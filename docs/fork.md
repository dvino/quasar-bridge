# Сборка с модулем собеседника

Форк [Quasar Bridge](https://github.com/skrashevich/quasar-bridge), база — v0.7.6.
Дополнения: явные разговорные сессии, игры без инструментов управления,
профили контекста и ограниченная долговременная память.
Статус: кандидат для испытаний под наблюдением взрослого, не средство родительского контроля.
[Результаты релизных проверок](verification.md).
[Проверки кандидата с автоматической озвучкой](automatic-voice-verification.md).

## Устройство

Один бинарник, без дополнительной службы или сетевого протокола.

- `cmd/quasar-bridge/companion.go`: настройки и подключение необязательного модуля.
- `internal/companion`: игры, профили, предпочтения, извлечение и хранение фактов.
- `internal/bridge`: адаптер к запросам колонки, маршрутизация, отмена,
  классификация аудитории и политика продолжения прослушивания.
- `internal/llm`: транспорт модели; модуль собеседника пока использует его тип сообщений.

Специфичные для установки обработчики и пробники моделей в сборку не входят.
По умолчанию управление устройствами использует штатные пути Яндекса и Home Assistant.
При необходимости можно подключить доверенный локальный обработчик (см. ниже).

Это внутренний модуль, не стабильный сторонний plugin API. Адаптер зависит от
Bridge и требует проверки при обновлениях. Игровые ответы обходят Assistant
и инструменты устройства. Вне игры обычные команды сохраняют штатную маршрутизацию.
Сессии ограничены и отменяются при прерывании; поздние результаты не должны
попадать в новый разговор. Эти контракты покрываются регрессионными тестами.

## Включение

Дополнения включаются переменными окружения процесса. На колонке — через
`runtime.env` в каталоге состояния; после изменения нужен перезапуск.
Значения `1` включают переключатели, отсутствие переменной выключает их.

| Переменная | Назначение |
| --- | --- |
| `QUASAR_EXPLICIT_DIALOGUE=1` | Отдельные разговорные сессии вместо постоянного продолжения |
| `QUASAR_SEMANTIC_DIALOGUE=1` | LLM-классификация начала, продолжения и завершения; требует explicit dialogue |
| `QUASAR_CHILD_COMPANION=1` | Игры и семейный собеседник |
| `QUASAR_AGE_ROUTING=1` | Контекст аудитории из уверенной классификации текущего запроса |
| `QUASAR_FAMILY_PROFILE` | Путь к одобренному общему профилю |
| `QUASAR_CHILD_PROFILE` | Путь к детскому профилю |
| `QUASAR_CHILD_PREFERENCES` | Путь к файлу сохраняемых предпочтений |
| `QUASAR_LEARNED_MEMORY_DIR` | Существующий каталог для `adult.json`, `child.json`, `family.json` |
| `QUASAR_ADULT_PROFILE` | Путь к общему взрослому профилю; доступ только при явном opt-in ниже |
| `QUASAR_ALL_ADULTS_OWNER=1` | Все уверенно определённые взрослые, включая гостей, используют взрослый профиль |

Не включайте последний переключатель для конфиденциального профиля.
Название сохранено для совместимости: он **не распознаёт владельца**.
Классификация пола не предоставляет доступ к взрослому профилю.
Неизвестная или неоднозначная аудитория получает семейные ограничения.

Минимальный набор для разговорных испытаний:

```sh
QUASAR_EXPLICIT_DIALOGUE=1
QUASAR_SEMANTIC_DIALOGUE=1
QUASAR_CHILD_COMPANION=1
QUASAR_AGE_ROUTING=1
```

Профили и запись памяти при этом не включены.
Примеры запуска: «давай поиграем», «давай поболтаем»;
завершение: «закончить игру». При семантической классификации намерение
завершения оценивается в контексте, а не только по отдельному стоп-слову.

### Модели

По умолчанию классификатор использует настроенную модель LLM. Переопределения:
`QUASAR_DIALOGUE_CLASSIFIER_MODEL`, `QUASAR_DIALOGUE_CLASSIFIER_EFFORT`.
Классификатор не получает hosted tools.

Опциональная маршрутизация (`QUASAR_DIALOGUE_MODEL_ROUTING=1`):

| Настройка | Внутренний класс |
| --- | --- |
| `QUASAR_DIALOGUE_FAST_MODEL` | `luna`, быстрые ответы |
| `QUASAR_DIALOGUE_REASONING_MODEL` | `terra`, рассуждения |
| `QUASAR_DIALOGUE_ADVANCED_MODEL` | `sol`, сложные запросы |

Имена классов — внутренние метки, не идентификаторы моделей провайдера.
Незаполненное соответствие сохраняет основную модель. Поддержка параметра
reasoning effort и дополнительных ролей зависит от API. Проверяйте совместимость,
стоимость и задержку выбранных моделей до включения.

## Локальный обработчик команд

`QUASAR_LOCAL_COMMAND` — абсолютный путь к доверенному исполняемому файлу,
установленному отдельно от Bridge. По умолчанию выключен. Bridge вызывает его
с аргументом `match`, передавая текст запроса в stdin; обработчик печатает пустой
ответ или непрозрачный код действия. `match` не должен выполнять действий.
Для совпадения Bridge вызывает `run`, передавая код в stdin; обработчик печатает
краткий ответ. Коды ограничены 256 байтами, ответ — 4096 байтами, каждый вызов —
двумя секундами для `match` и 15 секундами для `run`. При ошибке `match`
действие не выполняется; ошибка или тайм-аут `run` не доказывает, что действие
не произошло. В активной игре обработчик
не вызывается, чтобы вымышленные команды не управляли устройствами.

Это доверенный код, не песочница: обеспечьте права на файл и каталог, не принимайте
скрипты из ненадёжных источников. Установка и настройки обработчика независимы
от обновлений Bridge; обработчик обязан сам проверять каждый код в `run`.

## Данные и ограничения

Профиль — JSON с полями `base` и `modules`. Модуль содержит `id`, `scope`
(`family`, `child`, `adult`), `triggers` и `content`.

```json
{"base":"Объясняй коротко и понятно.","modules":[{"id":"space","scope":"family","triggers":["космос"],"content":"Для объяснений используй простые примеры."}]}
```

Общий контекст выбирается только из модулей `family`, без личного `base`.
Не помещайте родительские заметки, пароли и чувствительные сведения в профили.
Профили и память отправляются настроенному провайдеру модели при использовании.
ASR и TTS остаются облачными сервисами Яндекса.

Память хранит ограниченные структурированные наблюдения, не полный журнал.
Файлы заменяются атомарно с правами `0600`; каталог должен принадлежать
пользователю процесса и иметь права `0700`. Используйте отдельный каталог состояния,
не каталог распакованного приложения и не Git. Память можно редактировать локально;
удаление выученных сведений не удаляет исходный профиль.

Возраст — вероятностный сигнал, не идентификация и не граница безопасности.
Разные люди одной категории могут разделять контекст. Подсказки модели не
гарантируют отсутствие нежелательных ответов. Детские испытания проводятся
со взрослым, с учётом условий и возрастных ограничений провайдера.
Журналы разговоров и `QUASAR_VOICE_CLASS_TRACE` по умолчанию не включайте.

## Обновления и сборка

- `checks`: race-тесты, vet, actionlint workflows, проверка публичного дерева, установка в BusyBox,
  сборка ARM64/ARMv7. `standalone release` можно запустить вручную для архивов
  без публикации релиза.
- `upstream candidate`: ежедневно проверяет стабильный upstream. Новый релиз
  объединяется в отдельную ветку `candidate/upstream-vX.Y.Z`, затем собирается
  теми же проверками. Конфликт останавливает процесс; `main` не меняется.
- После просмотра изменений и испытаний кандидат можно объединить в `main`.
  Upstream PR автоматически не создаётся.
- Публикация форка запускается только собственным тегом `vX.Y.Z-fork.N`.
  Upstream-теги не публикуют релизы форка. Не создавайте релизный тег до проверки
  на устройстве. CI не устанавливает программу на колонку.

Штатная установка обновления через Assistant отключена: она могла бы заменить
кастомную сборку официальной. Установщик форка использует только
`dvino/quasar-bridge/releases/latest/download`; опубликован `v0.7.6-fork.1`
для контролируемых испытаний. Не используйте официальный установщик upstream
для обновления этой сборки.

Артефакты кандидатов предназначены для ручных испытаний. Автоматическое
обновление устройства и миграция схемы памяти пока не реализованы.
Если на устройстве изменены служебные скрипты, штатная переустановка пакета может
заменить их: сначала сохраните и сравните эти файлы. Частная конфигурация
локального обработчика и его исполняемый файл устанавливаются отдельно.
Сохраняйте предыдущую программу отдельно; при откате программы не заменяйте
текущую память старой копией.

## Приёмка кандидата

1. Запустить CI, проверить оба ARM-архива и установку/откат в тестовой среде.
2. Проверить на колонке начало и завершение разговора, смену темы и прерывание.
3. Проверить музыку, таймеры, погоду и реальные команды вне игры.
4. В игре проверить, что вымышленные команды не выполняют действий.
5. Проверить неизвестную аудиторию, разделение контекста, отключение памяти
   и отсутствие нежелательных журналов.
6. Оценить слышимость, задержку, корректность и уместность ответов вместе со взрослым.

Зелёный CI не подтверждает качество голоса или безопасность содержания модели.
